# Boundary-condition files

This folder holds boundary-condition Python files generated by the `bc_gui`
mesh viewer/editor (see ../bc_gui/).

The default output path is `boundary_conditions_gui.py`; each successful
save also creates `boundary_conditions_gui.bak.py` containing the
previous version.  You can edit these files by hand in any text editor;
the GUI re-reads them with its Load button and round-trips them through
the same schema understood by `vfm_data_io.load_boundary_conditions`,
i.e. three top-level lists `PRESCRIBED`, `LINKING`, and `EXTERNAL`
plus optional `DESCRIPTION`, `LAST_UPDATED`, `MESH_SETTINGS`, and
`SOLVER_SETTINGS` metadata.  `MESH_SETTINGS` lets the GUI and
`run_vfm.py` rebuild the same virtual mesh before applying node-based
BCs.  `SOLVER_SETTINGS` lets the GUI and `run_vfm.py` reuse the saved
sample area, max iterations, and coefficient tolerance.

Valid DOF labels for the plate editor:
    U, V, W, W_X, W_Y, W_XY
Valid edge labels:
    left, right, bottom, top

`LINKING` entries normally tie one named DOF to the same value at all selected
nodes. Programmatic callers may additionally set `relation="rigid_affine"`,
use `dof="W"`, provide `slopeDof` (`W_X` or `W_Y`), and select an `x` or `y`
`sortDirection`. This adds homogeneous multipoint rows enforcing
`W_i - W_0 - (s_i - s_0) W_,s(0) = 0`. Pair it with an ordinary linking entry
for `slopeDof` to leave only rigid edge translation and rotation.

External-work groups: each entry in the `EXTERNAL` list may carry an
optional `value` key (the applied force or moment magnitude that pairs
with the virtual displacement from this group).  Use it when the
measurement MAT file produced by `Loading_Data/FromAbaqustoVFM.m` does
not include an `F` field; leave it blank to fall back to the MAT-file F
(legacy behaviour).  The GUI exposes this as the
"Applied force / moment" line edit in the Add/Edit External dialog.
